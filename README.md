# Ye1 医学论文检查

**在投稿前或修改过程中，找出论文中值得处理的问题。**

- 检查研究逻辑、结果与图表的一致性，以及参考文献和适用的报告规范。
- 给出问题位置、依据和修改建议；可在适合处理的 Word 稿件中添加原生批注。
- 按实际提供的材料说明检查范围，不能替代作者和专业审查。

试着说：“帮我检查这篇论文，重点看结果和图表是否一致，并在 Word 里批注。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-paper-review-skill.zip)，解压后保留完整的 `ye1-paper-review` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-paper-review` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-paper-review/SKILL.md)。
